# Cairn CfE Benchmarks: Final Import Guide

This is the simple, final flow to load official benchmark statements into Supabase.

## What this gives you

- Official benchmark statements extracted from Education Scotland benchmark PDFs
- Mapped to Cairn curriculum areas and levels
- Linked to `cfe_outcomes` codes where available

Output file generated by script:
- `data/cfe-benchmarks-official-full.csv`

Current coverage in the generated file:
- `early`, `first`, `second`, `third_fourth`
- 8 Cairn curriculum areas
- Note: official benchmark publications do not provide a separate `senior` benchmark set in the same format.

## 1) Run schema files in Supabase

Run in this order in Supabase SQL Editor:

1. `schema.sql`
2. `cfe-seed.sql`
3. `schema-benchmarks.sql`

## 2) Generate the official benchmark CSV

From repo root:

```bash
npm run build:benchmarks
```

Prerequisites for this command:
- internet access
- `curl`
- `pdftotext` (Poppler)

What this script does:
- Downloads the official benchmark PDFs (if not already present) into `data/source/benchmarks/`
- Extracts benchmark bullet statements
- Builds `data/cfe-benchmarks-official-full.csv`

Script file:
- `scripts/build-official-benchmarks-csv.mjs`

## 3) Import CSV into Supabase

In Supabase:

1. Go to `Table Editor`
2. Open table `cfe_benchmarks`
3. Click `Insert` -> `Import data from CSV`
4. Upload `data/cfe-benchmarks-official-full.csv`

## 4) Create benchmark <-> outcome links

Run:

```sql
select public.link_benchmarks_from_related_codes() as links_created;
```

## 5) Validate import

```sql
select curriculum_area, level, count(*)
from public.cfe_benchmarks
group by curriculum_area, level
order by curriculum_area, level;
```

```sql
select count(*) as link_count
from public.cfe_outcome_benchmark_links;
```
